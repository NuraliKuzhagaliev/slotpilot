## Голосовая стабильность · 24 сентября 2026

- PCM-воспроизведение сглаживает краткие провалы между пакетами через границы аудиоблоков; очистка ответа затухает от последнего действительно воспроизведённого отсчёта, чтобы не создавать скачок громкости.
- Браузерное шумоподавление отключено при сохранённом эхоподавлении в соответствии с актуальной документацией AssemblyAI. Голосовые HTTP-запросы имеют таймаут 15 секунд вместо неограниченного ожидания; после таймаута записи результат остаётся неопределённым до серверной сверки.
- Локальные mock/PCM-проверки дополнены тестами короткого провала, очистки очереди и таймаута. Они не измеряют задержку реального ответа или звук на устройстве. Обновлённый живой разговор с серверным ключом AssemblyAI и микрофоном ещё необходим; утверждать стабильные 1–2 секунды нельзя.
- Проверки этой правки: `npm test` — 189/189; `npm run typecheck`, `npm run build:next` и `npm run build` (Vinext) — успешно; ESLint для изменённых JS-файлов — без замечаний. Общий `npm run lint` пока выдаёт 17 ошибок и 7 предупреждений в других, ранее существовавших файлах.

## Исправление блокировки голосового запуска · 24 сентября 2026

В опубликованной версии сообщение `Too many attempts` пришло из PostgreSQL rate limiter: для одного пользователя в namespace `slotpilot-public` было 7 попыток при ограничении 3 запуска за 10 минут. В той же серверной сессии уже было 10 записей о выдаче токенов за скользящие 24 часа при лимите 10. Раньше счётчик суточной квоты увеличивался ещё до ответа AssemblyAI, поэтому неудачная выдача токена тоже расходовала квоту.

Новая версия допускает до 10 попыток подключения за 10 минут, но сохраняет суточный лимит выданных токенов и общий предел 30. Неуспешная выдача токена либо отказ ограничителя освобождают зарезервированную суточную попытку. При суточном лимите интерфейс получает время, когда освободится первое место, в UTC. Уже сохранённые в базе старые записи о токенах автоматически не удаляются: достоверно отличить успешную выдачу от прежней неудачной попытки по ним нельзя.

Проверки: 190/190 тестов, TypeScript, Next/Vinext production build и ESLint для изменённых файлов проходят. Новый тест route handler проверяет отказ провайдера, возврат квоты, короткий лимит и успешную выдачу; реальный разговор этим тестом не подтверждается.
