# Следующий шаг: голосовая приёмка

Supabase создан и настроен: проект SlotPilot `lylcxxdrpralrstxzuct`, Lord Org, Free, Frankfurt. Миграция slotpilot_initial применена. Команды плагина доступны; браузер разрешён пользователем для недостающих возможностей. Не повторять подключение и не создавать ещё один проект.

1. Настроить серверный ASSEMBLYAI_API_KEY в секретах хостинга. Ключ есть на ноутбуке пользователя; не просить присылать его в чат.
2. Проверить реальный путь голос → подготовка → отдельное подтверждение → PostgreSQL → admin и перезагрузка.
3. На ноутбуке пользователя измерить слышимое перебивание; оценить ложные срабатывания на шум. Сделать минимум 10 живых прогонов и резервное видео.
4. Завершить требования Vitest/Playwright и голосовой перенос без ручного открытия нового запроса. P2 не блокирует основной показ.
5. Только после живых проверок пересмотреть полный статус P0/P1.

Основной проект, база, общие runtime-схемы и опубликованная версия уже существуют — не начинать заново с probe.
