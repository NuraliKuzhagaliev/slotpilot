# Результаты проверок · 23 сентября 2026

Это отчёт о фактически выполненных действиях, а не планируемых тестах.

## Выполнено успешно

`npm run check`: синтаксически проверено 20 JavaScript-модулей. Дополнительно статический поиск проверил отсутствие явных серверных переменных/заголовков с ключом в публичном исходном коде. Это ограниченная автоматическая проверка, не полный security audit.

`npm test`: **51 тест, 51 passed, 0 failed, 0 skipped**. Сохранён полный вывод `verification/node-tests.tap`. Проверены каталог/совместимость, дата филиала, вход/роль/сессия, Host/Origin, контракт инструмента, повтор callId, ограничения выдачи токенов, безопасные ошибки, очередность tools, устаревшие read-only ответы, частичные субтитры, PCM/ресемплинг, очистка playback и завершение сокета.

HTTP-тесты используют настоящий локальный Node HTTP-сервер. Ответы внешнего токенного API и события Voice Agent в автоматических тестах — контролируемые фикстуры. Реальный ключ не использовался. Проверки суммы 120 минут / 37 000 KZT относятся к арифметике тестового каталога, не к ещё не реализованному Constraint Engine.

`python tests/render_static_preview.py`: реально выполнены статические HTML/CSS-рендеры шириной 1440 и 390 px; горизонтального переполнения нет. Оба изображения просмотрены визуально. Скрипты приложения не выполнялись. В изображениях есть явная отметка о статическом предпросмотре.

Дополнительно в отдельной временной папке проверены `npm run setup` / скрипт setup: разные случайные пароли без вывода их значений, отказ от перезаписи существующего `.env.local`, исключение `.env.local` из Git при сохранении доступности `.env.example`. Настоящий API-ключ не использовался.

Политика управляемого браузера запрещает навигацию; полный прогон интерфейса не выполнен. Ни проверка login через UI, ни mock-аудиосценарий этим запуском не подтверждены. Ограничения браузера не обходились.
