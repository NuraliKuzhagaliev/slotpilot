# Бесплатное размещение и его границы

Цель — постоянный HTTPS-адрес, который открывается без запущенного ноутбука. Приложение подготовлено к serverless: голосовой WebSocket соединяет браузер с AssemblyAI, backend получает обычные короткие HTTP-запросы, PostgreSQL доступен через Supabase HTTPS RPC. Собственный долгоживущий WebSocket-сервер не требуется.

## Вариант A: текущий Sites

Приложение опубликовано; постоянная приватная ссылка: https://slotpilot-nurali.nurali6002217.chatgpt.site . Исходники сохранены в репозитории проекта. Публикация не превращает её в публичную ссылку для жюри. Публичный доступ нужно включать отдельно после настройки паролей, секретов и лимитов.

В серверном окружении требуются ключи из `.env.example`. Их можно задать через доступное подключение сервисов либо настройки хостинга; не через поле в публичном frontend и не сообщением с ключом в чат. Секреты базы и тестовых ролей уже настроены в Sites. Голос пока выключен до добавления ASSEMBLYAI_API_KEY.

## Вариант B: Vercel Hobby + Supabase Free

Подходит для личного некоммерческого хакатонного демо в пределах бесплатных квот. Используйте существующий личный аккаунт и бесплатный план. Не выбирайте Pro и не создавайте платные ресурсы.

1. Создать свой GitHub-репозиторий из проекта без `.env.local`, node_modules, .next, .wrangler и `.sites-runtime`.
2. В Supabase создать **отдельный бесплатный** проект; выполнить `supabase/migrations/001_slotpilot.sql` в SQL Editor.
3. В Vercel импортировать репозиторий. Preset: Next.js. Install: `pnpm install --frozen-lockfile`. Build: `pnpm run build:next`. Node: 22 или 24. Эти значения также заданы в `vercel.json`.
4. Внести серверные переменные из локального `.env.local` в Environment Variables Vercel. Ни одна секретная переменная не должна начинаться с NEXT_PUBLIC_. Включить минимум Production; preview-окружение должно иметь отдельный DEMO_NAMESPACE.
5. Настроить Supabase Auth: Site URL и Redirect URL на публичный адрес, собственный SMTP для отправки писем. Зарегистрировать владельца и подтвердить email. Роли в форме входа нет: выберите пользователя в **Authentication → Users**, укажите `{"role":"admin"}` именно в **App Metadata** (не User Metadata), сохраните, затем выйдите из приложения и войдите снова. Для входа используются email и пароль этой учётной записи; слово «admin» вводить не нужно. Без SMTP публичная регистрация для всех адресов не работает.
6. Опубликовать и открыть HTTPS-адрес. Проверить регистрацию, восстановление, клиент/админ в разных профилях браузера, запись, reload, перенос и конфликт.

## Чего бесплатный тариф не гарантирует

Supabase Free на дату проверки указывает 500 MB БД, два активных проекта и **приостановку после недели бездействия**. Поэтому «в любое время навсегда без обслуживания» обещать нельзя. Перед защитой проверить состояние проекта и возобновить его при необходимости. Не имитировать нагрузку для обхода правил тарифа.

AssemblyAI оплачивается отдельно от хостинга. Предоставленный API key не означает безлимит: голос расходует кредиты/баланс. Лимиты приложения по умолчанию: одна сессия максимум 5 минут, 3 выдачи токена за 10 минут на браузерного пользователя, 10 за 24 часа на пользователя и 30 за 24 часа на всё демо. Это ограничение вызовов, не жёсткий денежный лимит в аккаунте. Для тестов используйте выданные кредиты; не включайте автоматическую оплату без решения владельца.

Никаких платных ресурсов при подготовке этого пакета не создано.
