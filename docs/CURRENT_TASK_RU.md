# Текущая задача
Пользователь разрешил полноценную реализацию и потребовал учитывать бесплатное размещение. Живой probe пройден пользователем; задержка перебивания требует улучшения.
Цель: подключить сохранённое ядро к полноценному UI и PostgreSQL, реализовать P0/P1 безопасные операции, голосовой транспорт и admin/demo.
Работа интегратора охватывает app/, src/, public/audio/, agents/, supabase/, tests/, docs/ и общую конфигурацию. Публичные контракты stage1a сохраняются и расширяются централизованно.
Проверки: прежние тесты ядра; новый сервер и атомарные операции, строгие типы и production build. Живой микрофон и размещённая Supabase проверяются отдельно при наличии секретов.
Sites использует совместимую с Next App Router сборку Vinext; обычный Next.js локальный запуск предусмотрен отдельно. PostgreSQL не заменяется SQLite или browser storage.
