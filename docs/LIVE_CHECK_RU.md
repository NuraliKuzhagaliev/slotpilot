# Живая проверка этапа 0

**Этот файл — инструкция, не отчёт об уже выполненном разговоре.**

## До разговора

Запустите проект по README. Проверьте, что ключ находится только в `.env.local`. Подтвердите доступ аккаунта к Voice Agent API и кредитам. Используйте вымышленные данные. Не присылайте скриншоты с ключом, паролем или временным токеном.

Для первого прогона используйте Chrome/Edge на своём ноутбуке и localhost. Совместимость реального аудио с этим браузером ещё нужно проверить. Мобильный статический скриншот не означает, что телефон может подключиться к этому loopback-серверу.

Вход: `client` и значение `DEMO_CLIENT_PASSWORD`. Кнопка **Check server** проверяет каталог без голоса и без расхода API. У petrol sedan четыре услуги; у EV нет замены масла. Эта ручная проверка не засчитывает прохождение voice tool round-trip.

## Короткий живой сценарий

1. Отметьте согласие на внешнюю обработку аудио. Нажмите **Start voice check**, разрешите микрофон. Ожидаются приветствие и состояние подключения.
2. Скажите: **“What services do you offer for a petrol sedan?”** Ожидается `get_services` с сервера, карточки каталога и голосовой ответ на его основе. Должны появиться финальные субтитры вашей реплики.
3. Во время достаточно длинного ответа скажите: **“Wait, tell me only about oil changes.”** Проверьте, что старый звук прекращается и агент учитывает новую реплику. Само наличие события не доказывает прекращение слышимого звука.
4. Только после проверки отметьте **I actually heard the agent’s response** и **I verified playback stopped when I interrupted**. Экран должен различать наблюдаемые события и вашу ручную оценку.
5. Нажмите Stop. Проверьте прекращение звука и исчезновение браузерного индикатора захвата микрофона. Сохраните **Export this check’s evidence**.

Повторите один раз с новым Start, убедившись, что нужен новый временный токен. По умолчанию лимит — три попытки за десять минут; не обходите его перезапусками ради бесконтрольного тестирования.

Запрос **“Book me an oil change tomorrow”** на этом этапе не должен создавать запись. Агенту явно задано объяснить, что сейчас доступна только проверка голоса и каталога. В сервере нет операции бронирования, независимо от фразы модели.

## Что прислать после прогона

JSON-экспорт результатов без секретов, название/версию браузера, была ли слышна речь, сработало ли перебивание. При ошибке — безопасный код из интерфейса и действие, на котором она возникла. Не отправляйте `.env.local`, token endpoint payload, полные WebSocket URL или скриншоты Network с токеном.

Десять живых прогонов основной записи из ТЗ нужны позже, после реализации бронирования. Эта проверка не заменяет ту серию и не измеряет успешность ещё не написанного продукта.

## Ошибки и корректная реакция

| Симптом | Что проверить |
|---|---|
| `KEY_NOT_CONFIGURED` | Переменную ASSEMBLYAI_API_KEY в `.env.local`; затем перезапуск сервера |
| Неверный пароль | Username client и именно значение DEMO_CLIENT_PASSWORD, без имени переменной |
| `MIC_PERMISSION_DENIED` | Разрешение микрофона у браузера и ОС; наличие подключённого устройства |
| `PROVIDER_NOT_AUTHORIZED` | Действительность ключа и разрешение Voice Agent API в аккаунте; не подменять интеграцию другим STT API |
| `CONNECT_TIMEOUT` / `WEBSOCKET_ERROR` | Доступность сервиса, сеть, Voice Agent доступ и кредиты; автоматического mock fallback нет |
| `RATE_LIMITED` | Лимит попыток; дождаться окна, проверить расход аккаунта перед новым запуском |
| Голос есть, `get_services` нет | Явно спросить услуги для petrol sedan; сохранить экспорт события tool.call/tool.result |
| Нет слышимого голоса, но есть audio event | Вывод аудио, громкость, устройство; НЕ отмечать ручной пункт успеха |
| `ERR_BLOCKED_BY_ADMINISTRATOR` | Локальный запуск в разрешённой среде; не обходить корпоративные политики |

## Когда этап считается пройденным

Реальный аккаунт подключился; финальная пользовательская речь распознана; слышен ответ; инструмент реально прошёл через сервер и вернулся агенту; перебивание проверено на слух; Stop прекращает захват. Успех должен быть подтверждён человеком, а не выведен из наличия API-ключа или 51 автоматического теста.
